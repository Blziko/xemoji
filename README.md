# Xemoji
A fast TUI emoji and icon picker for Linux (X11), built with fzf and xclip for seamless integration.

### Requirements
- bash
- fzf
- sed
- grep
- findutils
- xclip

### Installation
```bash
cd /opt
git clone https://github.com/Blziko/xemoji
chmod +x xemoji/xemoji.sh
ln -sf xemoji/xemoji.sh /usr/bin/xemoji
cd
```

### Usage
```bash
xemoji
```
